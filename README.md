## How I work

- Start with the user journey, then design the smallest reliable system behind it.
- Treat loading, error, empty, and permission states as part of the feature.
- Prefer clear boundaries over clever abstractions.
- Measure before optimizing, and document trade-offs.
- Turn claims into evidence through demos, tests, and reproducible setup.
